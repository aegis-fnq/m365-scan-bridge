# repo-template
Template for new aegis-fnq repositories: callers to the shared workflows, never copies.

Create repositories from this template with `scripts/new-repo.sh` in
[`aegis-fnq/.github`](https://github.com/aegis-fnq/.github), not with the "Use this template"
button. A template copies files only; the script also turns on auto-merge, which a repository
made any other way does not get. If one was made with the button, run the script against it.
